Purpose and current behavior

The agent reads the public SmartRecruiters Posting API for the CityOfNewYork company. It currently selects external Department of Transportation and Department of Sanitation postings and records job descriptions, qualifications, compensation, deadlines, and official application links in a private review dashboard.

Discovery runs every six hours from an Oracle Cloud server at the fixed IPv4 address above. Requests use the dedicated User-Agent. The connector follows bounded pagination and stops on unsuccessful responses, including HTTP 403 and 429.

Applications and access policy

Public discovery does not submit job applications or create application approvals. Protected SmartRecruiters application forms are handled separately through manual browser interaction. The public discovery connector does not solve challenges, rotate identities, or call private candidate endpoints.

This page documents the deployed agent identity. It does not claim DataDome verification or authorization from any destination website. Any future protected automation remains subject to verification and the destination's access policy.

Data handling and contact

The public discovery connector collects public job-posting information. Applicant information, credentials, private application records, and API tokens are not published in this documentation or IP list.

Site operators can contact malcom@mjgil.com about the agent, its traffic, or an access-policy request.
